# Proyecto Retail - Machine Learning

Este proyecto contiene una estructura base para el desarrollo de modelos de machine learning aplicados al sector retail.

## Estructura de carpetas
- `data/raw`: Datos originales sin procesar.
- `data/processed`: Datos ya procesados y listos para modelado.
- `notebooks`: Jupyter Notebooks para exploración y experimentos.
- `models`: Almacenamiento de modelos entrenados y scripts relacionados.
- `app`: Aplicación Streamlit para visualización y despliegue.
- `docs`: Documentación del proyecto.

## Requisitos
Instala las dependencias con:
```
pip install -r requirements.txt
```

## Uso
1. Coloca los datos originales en `data/raw`.
2. Procesa los datos y guarda los resultados en `data/processed`.
3. Desarrolla y experimenta en los notebooks.
4. Entrena y guarda modelos en `models`.
5. Despliega la app con Streamlit desde la carpeta `app`.
